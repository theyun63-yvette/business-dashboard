# 行业阶段看板 · P0 原型

三市场（A 股 / 港股 / 美股）29 个行业节点的阶段定位看板。每天跑一次脚本，产出单页 HTML。

## 怎么用

```bash
# 联网重跑（约 40 秒，32 个标的）
python3 dashboard/pipeline.py

# 用本地缓存重跑（改样式、调指标时用，不打上游）
python3 dashboard/pipeline.py --offline
```

产出 `dashboard/行业阶段看板.html`，**双击即可打开**。ECharts 已内联进 HTML，不依赖任何 CDN，断网也能看。

## 目录

```
dashboard/
├── industries.csv          # 唯一的配置入口：改行业只需改这张表
```

## 加行业 / 换标的

编辑 `industries.csv`，一行一个标的：

```csv
market,sector,code,name_cn,role
A股,信息技术,sh512480,半导体ETF,industry
A股,基准,sh000300,沪深300,benchmark
```

- `role=industry` 是行业节点，`role=benchmark` 是该市场的超额收益基准（每个市场必须有一个）
- 代码前缀：`sh`(50/51/52/56/58 开头)、`sz`(15/16/18 开头)、`hk`(5 位数字)、`us`(美股代码)
- 加完直接重跑，无需改代码；历史不足 250 根会被自动跳过并打印原因

## 指标口径

| 字段 | 含义 |
|---|---|
| `mom` | 景气度 0-100 ＝ 55% `mom_cs` ＋ 45% `mom_ts` |
| `mom_cs` | 跨行业相对分位：20/60/120 日超额收益加权后，在当日全部节点中排名 |
| `mom_ts` | 自身历史分位：同一指标在该标的自身上下文中的位置 |
| `crowd` | 拥挤度 ＝ 成交额占同市场行业节点的比重，取自身 5 年分位 |
| `pos` | 价格在近 5 年区间的分位（估值位置的代理，非真实 PE 分位） |
| `stage` | 当日真实象限，决定散点颜色 |
| `stage_conf` / `pending` | 连续 3 日同象限才确认；未确认时 `pending=true`，散点画虚线圈 |
| `moved` | 今日是否发生确认级迁移（`stage_days` 归 1） |

象限：景气度 ≥ 50 且拥挤度 < 50 = **主升**；两者都高 = **过热**；景气度 < 50 且拥挤度 ≥ 50 = **出清**；两者都低 = **潜伏**。

为什么景气度要做「横比 + 纵比」：只做横比时，全市场普跌也一定有排名前 50% 的行业，会把一半行业误判成主升；只做纵比又会忽略相对强弱。两者各占一半的原因是——横比告诉你「现在谁比谁强」，纵比告诉你「它相对自己的历史算不算强」。

## 已知缺口（页面上也标注了）

- 景气度是**价格动量代理**，没有接入盈利与估值数据
- 事件与新闻维度未启用（P1）
- 港股只有 3 个节点，港股行业 ETF 供给太薄，拥挤度不代表全市场
- 美股没有日频资金流数据，拥挤度只能用成交额占比代理
- 电力 ETF 上市不足 5 年，分位按可得区间算

## 数据源

- A 股 / 港股行情：腾讯 `web.ifzq.gtimg.cn`（前复权）
- A 股长历史：新浪 `CN_MarketData.getKLineData`（未复权，用腾讯前复权价做锚点拼接）
- 美股：新浪美股 `US_MinKService.getDailyK`，失败时退到 Yahoo chart

详细的接口验证结论见上一级目录 `行业阶段看板_数据源清单.md` 第 13 节。
