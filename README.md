# 行业阶段看板 · Business Dashboard

一个把「行业处于什么阶段」从主观判断变成可计算位置的看板原型。覆盖 A 股 / 港股 / 美股共 29 个行业节点，每日更新。

一句话定位：**每天 5 分钟，回答三个问题——哪些行业正在起来、处在哪一段、今天什么推动了它。**

## 怎么打开原型

下载 `行业阶段看板.html` 后双击即可，**无需联网**。ECharts 已内联进 HTML，不依赖任何 CDN、服务器或账号。

页面包含：市场切换 → 四张指标卡 → 行业阶段地图（散点四象限）→ 市场概览 → 行业阶段榜 → 数据说明。散点支持悬停查看每个行业的完整指标与分解值。

## 核心方法

阶段由两个可计算的维度交叉得到，都取 0–100 的相对分位：

- **景气度**：20/60/120 日超额收益加权后，55% 跨行业相对分位 + 45% 自身 5 年历史分位
- **拥挤度**：成交额占同市场行业节点的比重，在自身历史中的分位

两轴以 50 为界切成四段生命周期：

| 阶段 | 景气度 | 拥挤度 | 含义 |
|---|---|---|---|
| 潜伏 | 低 | 低 | 基本面未起，资金未进 |
| 主升 | 高 | 低 | 景气已改善，资金尚未涌入 |
| 过热 | 高 | 高 | 景气好但交易已拥挤 |
| 出清 | 低 | 高 | 景气转弱，资金还没走 |

对应真实节奏：发现 → 共识 → 拥挤 → 瓦解。

### 一个刻意的设计选择

散点颜色永远取**当日真实象限**，而持续天数与阶段迁移用**连续 3 日确认**。两者不一致时，标记为「待确认」（虚线圈）而不是强行统一——因为一旦图上的位置和表格里的文字对不上，看图的人第一反应就是程序错了。稳定性用独立标记表达，不用视觉欺骗换取平滑。

## 数据范围

- 29 个行业节点：A 股 15、港股 3、美股 11（用行业 ETF 作为行业代理）
- 截面日期：2026-11-19
- 数据源：腾讯财经、新浪财经公开接口，全部免费、无需 API Key

## 已知边界

- 景气度目前是**价格动量代理**，尚未接入盈利与估值数据
- 港股行业 ETF 供给极薄，仅 3 个节点，不代表港股全市场
- 美股无免费日频资金流，拥挤度只能用成交额占比近似

完整缺口清单见 PRD 第 9 节。
