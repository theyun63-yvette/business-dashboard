# 行业阶段看板 · Business Dashboard

一个把「行业处于什么阶段」从主观判断变成**可计算位置**的看板。覆盖 A 股 / 港股 / 美股共 29 个行业节点，每日跑一次脚本即可更新。

一句话定位：**每天 5 分钟，回答三个问题——哪些行业正在起来、处在哪一段、今天什么推动了它。**

**在线浏览：<https://theyun63-yvette.github.io/business-dashboard/>**

下载 [`行业阶段看板.html`](./行业阶段看板.html) 后双击打开，**无需联网**。ECharts 已内联，不依赖 CDN、服务器或账号。

## 核心方法

阶段由两个可计算维度交叉得到，均取 0–100 的相对分位：

- **景气度**：20/60/120 日超额收益加权后，55% 跨行业相对分位 + 45% 自身 5 年历史分位
- **拥挤度**：成交额占同市场行业节点的比重，在自身历史中的分位

两轴以 50 为界切成四段：

| 阶段 | 景气度 | 拥挤度 | 含义 |
|---|---|---|---|
| 潜伏 | 低 | 低 | 基本面未起，资金未进 |
| 主升 | 高 | 低 | 景气已改善，资金尚未涌入 |
| 过热 | 高 | 高 | 景气好但交易已拥挤 |
| 出清 | 低 | 高 | 景气转弱，资金还没走 |

对应真实节奏：发现 → 共识 → 拥挤 → 瓦解。

### 两个刻意的设计选择

**① 双轨制。** 散点颜色永远取当日真实象限，而持续天数与迁移用「连续 3 日同象限」确认。两者不一致时标为「待确认」（虚线圈），不强行统一——图上的位置和表格里的文字一旦对不上，看图的人第一反应就是程序错了。

**② 景气度必须混合横比与纵比。** 只做横截面分位时，全市场普跌也一定有排名前 50% 的行业，会把一半行业误判成「主升」。加入 45% 的自身历史分位后，普跌日整体分数下移，多数行业正确落到出清/潜伏。

## 数据范围

- 29 个行业节点：A 股 15、港股 3、美股 11（用行业 ETF 作为行业代理，规避三市场行业分类口径不一致）
- 截面日期：2026-11-19
- 数据源：腾讯财经、新浪财经公开接口，全部免费、无需 API Key

## 已知边界

- 景气度目前是**价格动量代理**，尚未接入盈利与估值数据
- 港股行业 ETF 供给极薄，仅 3 个节点，不代表港股全市场拥挤度
- 美股无免费日频资金流，拥挤度只能用成交额占比近似
- 价格位置用价格分位代替 PE 分位，对周期股会失真

完整缺口清单见 [`看板PRD1.0.md`](./看板PRD1.0.md) 第 9 节。
